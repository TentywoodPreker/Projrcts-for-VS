
**Репозиторий с учебными и практическими проектами в области бизнес-аналитики, финансового анализа и Data Analytics, представленых для резюме.
В проектах представлены:
- Анализ и обработка данных.
- Статистические исследования и проверка гипотез.
- Финансовый анализ компаний и оценка экономических показателей.
- Исследование закономерностей и выявление факторов влияния.
- Визуализация данных и формирование аналитических выводов.
**Инструменты:** Python (Pandas, NumPy, Matplotlib, Scikit-learn), SQL, Excel, Power BI, Google Colab.
